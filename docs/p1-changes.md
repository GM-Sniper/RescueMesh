# P1 changes: workspace and proto v0 (Fri Oct 16)

## What was created
| File / folder | What it is | What you need to know |
|---|---|---|
| `Cargo.toml` (root) | Workspace file: lists the 4 crates and pins every library version once | To add a library, add it here with an exact version (`=x.y.z`), then opt in from your crate with `name.workspace = true` |
| `Cargo.lock` | Exact version of every library in the build (about 110, most pulled in by tonic) | Generated by Cargo and committed so all machines match. Never edit by hand |
| `.gitignore` | Keeps the `target/` build folder out of git | Build output differs per machine and can always be rebuilt |
| `proto/rescuemesh.proto` | Wire protocol v0: one RPC, `Node.Heartbeat` (`HeartbeatRequest{from_node, seq}` → `HeartbeatReply{node_id, seq}`) | Changes go through P1. Never change or reuse a field number |
| `crates/common/` | Library shared by every program | Put shared types here. P2's domain types go here on Saturday |
| `crates/common/build.rs` | Runs before `common` compiles; turns the proto into Rust (protox parses and checks it, tonic-prost-build generates the code) | Reruns automatically when the proto changes. A proto mistake shows up as a build error here |
| `crates/common/src/lib.rs` | Exposes the generated code as `common::pb` and defines `NodeId = u32` | Use `common::pb::HeartbeatRequest`, `common::pb::node_client::NodeClient`, `common::pb::node_server::Node` |
| `crates/node/` | Cloud node program, run on all 3 machines | Placeholder ("Hello, world!"). P1 builds the skeleton on Sunday |
| `crates/client/` | Client program | Placeholder. Owned by P6 |
| `crates/loadgen/` | Load generator for the stress tests | Placeholder. Owned by P6 |
| `README.md` | Setup steps, layout and team rules | Read this first |

## Build
`git clone https://github.com/GM-Sniper/RescueMesh`, then `cargo build`. Generated code ends up in `target/debug/build/common-*/out/rescuemesh.v1.rs` (never edit it; change the proto instead).

## Decisions
| Decision | Why |
|---|---|
| protox instead of protoc | Pure Rust, no install on any laptop or lab machine. Ignore "install protoc" in the Step A plan. |
| Library versions pinned exactly (`=`) in the root `Cargo.toml` | Every machine builds the same thing; tonic, tonic-prost and tonic-prost-build must match. |
| Node IDs start at 1; 0 means a client | In proto3 a zero field is not sent, so 0 cannot be told apart from "unset". |
| Heartbeat is unary | A missing reply before the deadline is the failure signal for the detector. |
| No timestamp in Heartbeat | The caller measures round-trip time with its own clock; the machines' clocks differ. |
